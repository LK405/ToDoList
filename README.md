# Proyecto EjemploClaseVite

Este proyecto es una aplicación web creada con **Vite + React + TypeScript + Bootstrap**.  
Incluye componentes como `FormTaskAndGoal`, `Item`, `Menu` y `AddingMobileButton`.

## Actualización Semana 2
- Se agregó el manejo de datos reales usando **Zustand**.
- Ahora se pueden agregar y borrar tareas o metas desde el formulario.
- El menú ya es funcional y permite cambiar entre la lista de tareas y la de metas.
- Los datos se guardan y se muestran dinámicamente en la pantalla.

## Requisitos

- Node.js (versión 18 o superior recomendada)
- npm (incluido con Node.js)

## Instalación

1. Clona el repositorio y entra en la carpeta del proyecto.
2. Ejecuta `npm install` para instalar las librerías.
3. Ejecuta `npm run dev` para abrir la aplicación en el navegador.
